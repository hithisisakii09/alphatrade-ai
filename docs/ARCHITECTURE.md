# AlphaTrade AI v2.0 — System Architecture

## 1. Seven-Layer Deterministic Pipeline
1. **Market Data Sources (`app/data/providers.py`)**: Pluggable read-only adapters for [FYERS API v3](https://fyers.in/api-docs/v3/api/market-data/historical-data/), [Upstox Developer API v3](https://upstox.com/developer/api-documentation/v3/get-historical-candle-data/), [Angel One SmartAPI](https://smartapi.angelbroking.com/docs), and deterministic local CSV/fixture replay.
2. **Ingestion & Validation (`app/data/validator.py`)**: Validates 1-minute OHLCV invariants (`High >= max(Open, Close)`, `Low <= min(Open, Close)`, `Volume >= 0`), detects duplicates, out-of-order bars, stale feeds (`> 90s`), and `> 15%` overnight corporate-action gaps.
3. **Market Analysis (`app/market/indicators.py`)**: Session-aware VWAP, EMA(9, 20, 50), Wilder ATR(14), Time-of-Day Relative Volume (RVOL), 15-minute Opening Range (`09:15–09:30 IST`), and NIFTY 50 regime filter.
4. **Strategy & Eligibility (`app/strategy/orb/engine.py`)**: Long-only 5-minute confirmed close above Opening Range High (`ORH`), price above VWAP, `RVOL >= 1.5x`, spread `<= 0.15%`, and `>= 3.0%` headroom below the daily upper circuit limit ([NSE Price Bands](https://www.nseindia.com/static/products-services/equity-market-price-bands)).
5. **Risk Management (`app/risk/engine.py`)**: Independent deterministic gate enforcing `1.25%` initial stop (or ORB Low, bounded `0.50%–1.50%`), `+2.50%` (`+2R`) trailing activation, `0.75%` trailing drop, whole-share sizing on the ₹1,00,000 Standard Research Ledger (or ₹10,000 Micro Ledger), `15%` max cost-to-risk ratio, `1.5%` daily loss kill switch, and `14:30 IST` entry cutoff.
6. **Paper Broker & Portfolio (`app/execution/paper_broker.py`, `app/portfolio/ledger.py`)**: Next-bar open fill simulation with half-spread and adverse slippage, NSE circuit-freeze checks, statutory Indian fee engine ([Zerodha Brokerage Calculator](https://zerodha.com/brokerage-calculator/)), idempotent order keys, and SQLite/PostgreSQL restart recovery.
7. **Reporting, Backtesting & API (`app/backtest/engine.py`, `app/api/routes.py`)**: 1-minute bar-by-bar chronological backtester with pessimistic intrabar stop priority, walk-forward validation, and read-only FastAPI endpoints + HTML dashboard.
