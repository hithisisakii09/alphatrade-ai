# Milestone M19: Hidden Markov Model Volatility Regime Classifier

## 1. Executive Summary

Milestone **M19** implements an institutional quantitative **Hidden Markov Model (HMM) Volatility Regime Classifier** operating directly on intraday OHLCV candle streams for the Indian Equities market (NSE Cash).

The module eliminates arbitrary rolling volatility cutoffs in favor of a mathematically rigorous 3-state Gaussian emission model fitted via the **Baum-Welch Expectation-Maximization (EM)** algorithm and decoded via the **Viterbi** dynamic programming algorithm.

Signals generated by the intraday Opening Range Breakout (ORB) engine are filtered through Check 13 (`ADVERSE_REGIME`), which halts long entries whenever the underlying or index exhibits high-volatility, negative-drift regime states (`BEAR`).

## 2. Mathematical Architecture

### 2.1 State Space
The classifier categorizes market behavior into three distinct latent states $S \in \{0, 1, 2\}$:
1. **State $S_{\text{BULL}}$**: Low-to-moderate variance, positive drift ($\mu_{\text{ret}} > 0, \sigma_{\text{ret}} \le \sigma_{\text{median}}$).
2. **State $S_{\text{NEUTRAL}}$**: Moderate variance, mean-reverting drift ($\mu_{\text{ret}} \approx 0$).
3. **State $S_{\text{BEAR}}$**: High variance, negative drift ($\mu_{\text{ret}} < 0, \sigma_{\text{ret}} > \sigma_{\text{median}}$).

### 2.2 Feature Vector
For each 1-minute bar $t$, the observation vector $\mathbf{x}_t \in \mathbb{R}^2$ consists of:
$$\mathbf{x}_t = \begin{bmatrix} r_t \\ \rho_t \end{bmatrix} = \begin{bmatrix} \ln\left(\frac{C_t}{C_{t-1}}\right) \\ \frac{H_t - L_t}{C_{t-1}} \end{bmatrix}$$
where:
- $r_t$ is the log-return of bar close relative to the prior close.
- $\rho_t$ is the normalized intrabar range (proxy for localized realized volatility).

### 2.3 Parameter Estimation (Baum-Welch Algorithm)
The model parameters $\boldsymbol{\lambda} = (\boldsymbol{\pi}, \mathbf{A}, \boldsymbol{\mu}, \boldsymbol{\Sigma})$ are learned iteratively:
- **Forward Variable $\alpha_t(i)$**: Log-space probability of observing $\mathbf{x}_{1:t}$ and being in state $i$ at time $t$.
- **Backward Variable $\beta_t(i)$**: Log-space probability of observing $\mathbf{x}_{t+1:T}$ given state $i$ at time $t$.
- **State Posterior $\gamma_t(i)$**:
  $$\gamma_t(i) = P(q_t = S_i \mid \mathbf{X}, \boldsymbol{\lambda}) = \frac{\alpha_t(i)\beta_t(i)}{\sum_{j=1}^N \alpha_t(j)\beta_t(j)}$$
- **Transition Posterior $\xi_t(i, j)$**:
  $$\xi_t(i, j) = P(q_t = S_i, q_{t+1} = S_j \mid \mathbf{X}, \boldsymbol{\lambda}) = \frac{\alpha_t(i) A_{ij} b_j(\mathbf{x}_{t+1})\beta_{t+1}(j)}{\sum_{k=1}^N \sum_{m=1}^N \alpha_t(k) A_{km} b_m(\mathbf{x}_{t+1})\beta_{t+1}(m)}$$

### 2.4 Viterbi State Decoding
The optimal sequence of hidden states $\mathbf{q}^* = (q_1^*, \dots, q_T^*)$ is retrieved by maximizing:
$$V_t(j) = \max_i \left( V_{t-1}(i) + \ln A_{ij} \right) + \ln b_j(\mathbf{x}_t)$$

## 3. ORB Strategy Integration: Check 13 (`ADVERSE_REGIME`)

In `app/strategy/orb/engine.py`, candidate breakout signals undergo sequential evaluation:
```python
# 13. HMM Volatility Regime filter
if getattr(self.config, "require_regime_filter", False) and regime_state is not None:
  allowed = getattr(self.config, "allowed_regimes", ["BULL", "NEUTRAL"])
  if regime_state.regime.value not in allowed:
    return ORBSignalEvaluation(
        symbol=sym,
        session_date=session_date,
        timestamp_utc=bar_5m.timestamp_utc,
        triggered=False,
        signal_id=None,
        signal_price=bar_5m.close,
        orb_high=orb_state.orb_high,
        orb_low=orb_state.orb_low,
        vwap=vwap,
        rvol=rvol,
        rejection_reason="ADVERSE_REGIME",
        explanation=(
            f"Rejected: Current volatility regime is {regime_state.regime.value} "
            f"(confidence={regime_state.confidence:.1%}). "
            f"Allowed regimes: {allowed}."
        ),
    )
```
